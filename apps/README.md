# Apps

These are common app stacks maintained by kelso. `kelso init` adds this folder
as the `staples` repo, so each one is a `kelso start <app>` away.

Start with [kelso-ui](kelso-ui.klso): it is kelso's web UI, and a big part of
how you interact with kelso once it is installed.

Most of these versions are the version of the docker image the app runs, so
an update here is an update of the app itself. kelso-ui and adguard-pause are
kelso's own and follow kelso's version.
